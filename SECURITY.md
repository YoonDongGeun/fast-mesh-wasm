# Security Policy

## Supported versions

Only the latest published version of `fast-mesh-wasm` receives security fixes.

## Reporting a vulnerability

Please do not report security issues in public issues or discussions.

Report them privately through [GitHub Security Advisories](https://github.com/YoonDongGeun/fast-mesh-wasm/security/advisories/new).
Include the affected version, a description of the issue and, if possible, a minimal reproduction.

You can expect a first response within 7 days. Once a fix is released, the advisory will be published with credit to the reporter, unless you ask otherwise.
